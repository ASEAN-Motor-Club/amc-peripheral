**Cops & Criminals** is the club's native law-enforcement system for Motor
Town. There is no game mod involved — the whole loop runs inside the club's
backend and talks to the game server through its own interfaces.

## The loop

Illicit cargo makes you **Wanted** and puts a **bounty** on you. From there:

- **Police** can pull you over for inspection; a chase starts if you flee.
- Getting caught means an **arrest**, **jail time**, and **confiscation** of
  the illicit cargo.
- Logging out or going underwater during a chase has consequences too.

## What it is not

- It is not the third-party Schedule I pak — that was deprecated and replaced
  by this system.
- It is not RP Mode — RP Mode is the movement-restriction layer, this is the
  economy and chase layer. You can be RP-tagged and Wanted at the same time.
