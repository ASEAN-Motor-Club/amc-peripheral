Official AMC community mods — cargo packs, decals, tire mods and more —
are published on the main community site:

**[aseanmotorclub.com/releases/mods/](https://www.aseanmotorclub.com/releases/mods/)**

## Installation

Download the `.pak` file and place it in your Motor Town Paks directory:

```
Steam\steamapps\common\Motor Town\MotorTown\Content\Paks\
```

Restart the game after installing. Only the latest version of each mod
is needed.

## Schedule I

The *Schedule I* pak adds the **illicit cargo economy** — moonshine,
cocaine and meth supply chains, their precursor chemicals, and every
delivery point that buys the product. The server runs it automatically;
the client pak is **required** to interact with the modded sites.

- Download the latest client pak from
  [aseanmotorclub.com/releases/mods/](https://www.aseanmotorclub.com/releases/mods/)
  (the `Schedule_I_v*_0.7.19_CLIENT_P.pak` file) and drop it in your Paks
  folder as shown above.

Full reference: **[Schedule I](/schedule-i/)** — cargo, production and
delivery-point tables. The [Law & Order](/justice/) system layers the
criminal score, wanted chases and the boss tax on top of this economy.
