Official AMC community mods — cargo packs, decals, tire mods and more —
are published on the main community site:

**[aseanmotorclub.com/releases/mods/](https://www.aseanmotorclub.com/releases/mods/)**

## Installation

Download the `.pak` file and place it in your Motor Town Paks directory:

```
Steam\steamapps\common\Motor Town\MotorTown\Content\Paks\
```

Restart the game after installing. Only the latest version of each mod
is needed.

## Schedule I

The *Schedule I* pak historically added illicit cargo types and delivery
recipes to the criminal faction. **The native law-enforcement system
(described in [Law & Order](/justice/)) has replaced its gameplay** — the
illicit cargo economy now runs server-side without any mod.
