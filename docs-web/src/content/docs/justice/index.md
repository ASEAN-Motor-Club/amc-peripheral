The club runs a **native law-enforcement system**: there is no game mod
involved — the whole loop runs inside the club's backend and talks to
the game server directly. It replaced the third-party *Schedule I* pak.

## The loop

Hauling **illicit cargo** builds your **criminal score**; deliveries can
trigger a random **Wanted** status, police chase you, and an arrest
means **jail** plus **confiscation**. The money side (the boss tax, the
`/criminals` leaderboard) and the chase side are documented separately:

- [Money laundering & criminal faction](/justice/money-laundering/) — the
  score, decay, the boss tax.
- [Playing a criminal](/justice/criminals/) — wanted status, chases,
  jail, arrests.
- [Serving as police](/justice/police/) — duty-up, on-duty rules,
  compass intel, rewards.
